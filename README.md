# Pulse

A tiny iStat-style menu bar app for macOS. It shows CPU and memory in the menu
bar and, on click, a panel with a 2-minute CPU history, per-core load, load
average, thermal state, a memory breakdown (app / wired / compressed / cached,
swap, pressure) and the top 8 processes by CPU or memory.

Native Swift + SwiftUI, no dependencies. Builds with the Command Line Tools
alone; no Xcode project.

## Build and run

```sh
./build.sh            # builds build/Pulse.app
open build/Pulse.app

./build.sh --install  # also installs to /Applications/Pulse.app and relaunches it
```

To start it at login: System Settings → General → Login Items → add Pulse.

The app has no Dock icon. Quit it from the panel (or ⌘Q while it is open).

## How it samples

Every 2 seconds:

- **CPU** per core from `host_processor_info` (Mach), diffed between samples.
- **Memory** from `host_statistics64`, `vm.swapusage` and
  `kern.memorystatus_vm_pressure_level`. "Used" is app + wired + compressed,
  the same number Activity Monitor shows.
- **Processes** by running `/bin/ps -Aceo pid,pcpu,rss,comm`. Reading another
  user's process stats directly (`proc_pidinfo`) needs the Apple-private
  `com.apple.system-task-ports.read` entitlement that `ps` and `top` have and
  third-party apps cannot get. Without it, WindowServer, kernel_task and every
  daemon would be invisible, which defeats the point. `ps` costs ~30 ms per call.

## Layout

```
Sources/Pulse/
  PulseApp.swift   MenuBarExtra scene + menu bar label (rendered to an image)
  Monitor.swift    sampling, published on the main actor
  StatsView.swift  the panel
Info.plist         LSUIElement = true (no Dock icon)
Icon.icns          app icon, generated by scripts/make-icon.swift
build.sh           swift build + assembles and ad-hoc signs the .app
```

Note: the macOS 27 SDK makes SwiftUI's `@State` a macro whose plugin only
ships with Xcode, so view state uses `@AppStorage` / `ObservableObject` instead.
